# Podstawowe narzędzia wymagane do kursu devops

**curl**
* Narzędzie wiersza poleceń do przesyłania danych za pomocą różnych protokołów sieciowych, najczęściej używane do wysyłania zapytań HTTP/HTTPS i testowania API.

**wget**
* Program służący do pobierania plików z internetu (z protokołów HTTP, HTTPS i FTP) z możliwością wznawiania przerwanych pobierań.

**unzip**
* Narzędzie do rozpakowywania archiwów w formacie ZIP bezpośrednio z poziomu terminala.

**htop**
* Interaktywny menedżer procesów i monitor zasobów systemu operacyjnego (CPU, RAM) w czasie rzeczywistym.

**tree**
* Program wyświetlający zawartość katalogów w formie czytelnego, hierarchicznego drzewa katalogów i plików.

**jq**
* Lekki procesor danych JSON w terminalu, pozwalający na łatwe filtrowanie, formatowanie i przetwarzanie zapytań JSON.

**docker**
* Platforma do konteneryzacji.
