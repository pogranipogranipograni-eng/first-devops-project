# Assignment Requirements (LMS)

## Mandatory Steps:
1. Created account on GitHub (or equivalent provider)
2. Repository with a proper structure aligned with Git Flow
3. 10 commits on task branch no. 12* with valid commit messages:
   1. Add initial 3 files
   2. Write documentation
   3. Add tests
   4. Add CI configuration
   5. Add additional files
   6. Make corrections in files
   7. Refactor code
   8. Remove unused lines
   9. Add more files
   10. Make final adjustments

\* Note: For the branch name, I used the lesson number from the textbook for this specific task.
